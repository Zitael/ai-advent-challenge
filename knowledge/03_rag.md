# Retrieval Augmented Generation

## Что такое RAG

RAG позволяет дополнять знания модели внешними документами.

В отличие от fine tuning знания не встраиваются в веса модели.

Во время выполнения запроса происходит:

1. embedding вопроса;
2. поиск похожих документов;
3. добавление найденных документов в prompt;
4. генерация ответа.

---

## Индексация

Индексация включает:

- загрузку документов;
- chunking;
- генерацию embeddings;
- сохранение индекса.

---

## Chunking

Существуют разные стратегии.

### Fixed Size

Документ режется на куски фиксированного размера.

Преимущества:

- простота;
- одинаковый размер чанков.

Недостатки:

- может разрезать логический раздел.

---

### Structure Based

Документ режется по заголовкам и разделам.

Преимущества:

- сохраняет смысл разделов;
- лучше подходит для документации.

Недостатки:

- размеры чанков отличаются.
