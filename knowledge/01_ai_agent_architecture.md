# AI Agent Architecture

## Что такое AI-агент

AI-агент — это приложение, использующее LLM для принятия решений и выбора последовательности действий.

Типичная архитектура включает:

- LLM
- Memory
- User Profile
- State Machine
- Invariants
- Tool Router
- MCP
- RAG
- Scheduler

Сам по себе LLM не умеет хранить память, выполнять задачи по расписанию или обращаться к внешним API. Все эти возможности реализуются приложением вокруг модели.

---

## Agent Runtime

Agent Runtime отвечает за:

- сбор контекста;
- построение prompt;
- вызов инструментов;
- сохранение памяти;
- управление состояниями;
- применение ограничений.

---

## Оркестрация

При обработке запроса агент обычно выполняет следующие этапы:

1. Получает запрос пользователя.
2. Загружает память.
3. Загружает профиль пользователя.
4. Получает релевантные знания через RAG.
5. Строит prompt.
6. Выполняет запрос к LLM.
7. При необходимости вызывает MCP-инструменты.
8. Возвращает ответ.
