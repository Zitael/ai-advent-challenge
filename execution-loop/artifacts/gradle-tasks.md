# Gradle Tasks

- **runRagIndex** - Build local RAG document indexes
- **runRagAsk** - Ask a question with and without RAG
- **runRagChat** - Run interactive RAG chat with local Ollama model
- **runOllamaDemo** - Run three requests against a local Ollama model
- **runOllamaOptimization** - Compare baseline and optimized Ollama profiles
- **runPrivateAiServer** - Run private HTTP API backed by local Ollama
- **runDeveloperAssistant** - Run Day 31 developer assistant with project RAG and Git MCP
- **reviewPullRequest** - Review pull request diff with RAG and Ollama
- **runSupportAssistant** - Run Day 33 support assistant with RAG and CRM MCP
- **runProjectFileAssistant** - Run Day 34 assistant that searches, analyzes and modifies project files
- **prepareRelease** - Run Day 35 AI release preparation pipeline
- **runExecutionLoop** - Run Day 5 autonomous execution loop over task-pool.md
- **runSmokeTests** - Run Playwright smoke scenarios against Private AI UI
- **fullVerification** - Run code tests and UI smoke tests, then collect a unified report
